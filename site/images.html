Image checklist

Every screenshot the site needs, with the exact file name to save it as. Take them in a custom game, save them as JPG into the images/<map>/ folder, then rebuild. 0 of 462 added so far.

How to take them

  • Load a custom game with no enemies, once as defence and once as attack.
  • Stand in the doorway, aim at chest height and fit the whole room in.
  • Leave walls unbroken for the reinforce and breach shots.
  • 16:9, ideally 1920×1080. Name each file exactly as shown.

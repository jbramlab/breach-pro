Attack basics, any squad size

  • Hard breach the Lockers wall to Vault lobby from Vault lobby.
  • Open the Server room hatch for pressure from above.
  • Clear Bank garage so nobody flanks the plant.

If it goes wrong

If the Lockers wall to Vault lobby stays denied, push Secure hallway and Server stairs together with smokes and plant in CCTV room.

What it looks like in game

Defence basics, any squad size

  • Reinforce the Lockers wall to Vault lobby first. It is the main hard breach.
  • Reinforce the Server room hatch so attackers cannot drop in.
  • Watch Secure hallway and Server stairs. That is where the inside push comes from.

If it goes wrong

If the Lockers wall to Vault lobby opens early, fall back into CCTV room and play the plant instead of trading at the hole.

Set up once

  1. Custom game, Attack side, nobody on Defence. Attackers can walk inside and outside, so one load covers every shot.
  2. Settings: longest round and prep times, daytime, objective Bomb.
  3. Pick an operator with a 1x sight and don't aim down sights. Hide the HUD if your settings allow it.
  4. Screenshot key: Win + Alt + PrtScn. Files land in Videos › Captures.
  5. No renaming. Take the shots in the order shown. If you skip one, take a screenshot of the pause menu in its place so the order still lines up.
  6. Operators need no match: open Operators from the main menu and screenshot each one.
  7. After each map, put its screenshots in a folder named after the map (for example border) and send me all the folders at the end, zipped.
Ticks are saved on this device only.
